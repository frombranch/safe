# 저녁 스터디 큐

퇴근 후 남은 시간에 맞춰, 그날 볼 만한 **한국어 AI·디자인 유튜브 영상**만 골라 보여 주는 개인 위젯.

네 가지 주제를 매일 새로 훑는다.

| 주제 | 내용 |
| --- | --- |
| Claude Code 디자인 | 클로드 코드로 화면 만들고 프로토타이핑하기 |
| Figma × AI | 피그마 자동화, MCP, 디자인 시스템 연결 |
| AI 문서·리포트 | 제안서·기획서·리뷰 문서를 AI로 쓰기 |
| UX/UI × 생성형 AI | 포토샵·제미나이·이미지 생성 등 디자이너용 AI |

## 어떻게 고르는가

`search.list` 로 주제별 6개 쿼리를 돌려 후보를 모으고, `videos.list` 로 조회수·좋아요·러닝타임을 붙인 뒤
아래 점수로 정렬한다. 누적 조회수보다 **하루 평균 조회수(급상승 속도)** 에 가장 큰 가중치를 둬서,
"예전에 유명했던 영상"이 아니라 "요즘 사람들이 보는 영상"이 위로 올라온다.

```
점수 = log10(하루평균조회수 + 1)          ← 급상승 속도
     + log10(누적조회수 + 1) × 0.35        ← 누적 신뢰도
     + exp(-경과일 / 45) × 1.2             ← 최신성
     + min(좋아요/조회수, 0.1) × 4         ← 반응률
```

한 채널이 목록을 독점하지 않도록 주제당 채널 상한(기본 2편)을 두고,
제목에 한글이 없거나 오디오 언어가 한국어가 아닌 영상은 걸러 낸다.

## 위젯에서 할 수 있는 것

- **시간에 맞춰 재생목록 짜기** — 15분 / 30분 / 1시간 / 2시간을 고르면, 아직 안 본 영상 중 트렌드 상위부터
  그 시간 안에 들어가도록 담아 주고, `YouTube에서 이어보기` 로 한 번에 연속 재생한다.
- 주제 탭, 제목·채널 검색, 트렌드 / 최신 / 조회수 / 짧은 순 정렬
- `안 본 것만`, `20분 이하` 빠른 필터
- `봤어요` 표시 — 이 브라우저에만 저장되며(localStorage), 다음에 열면 흐리게 처리되고 재생목록에서도 빠진다

## 쓰는 법

### 1. YouTube Data API 키 발급 (최초 1회, 약 5분)

1. <https://console.cloud.google.com/> 접속 → 상단에서 **프로젝트 만들기** (이름은 아무거나)
2. 좌측 메뉴 **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
4. 생성된 `AIza...` 문자열을 복사

무료 할당량은 하루 10,000유닛이고 기본 설정으로 한 번 갱신할 때 약 2,430유닛을 쓴다. 결제 정보 등록은 필요 없다.

### 2. 데이터 받고 위젯 만들기

```bash
export YOUTUBE_API_KEY=AIza...
npm run refresh          # fetch.mjs → data.json → dist/widget.html
```

`dist/widget.html` 은 외부 의존성이 없는 단일 파일이라 브라우저로 바로 열거나 아티팩트로 발행하면 된다.

썸네일까지 넣고 싶으면 `node fetch.mjs --thumbs` 를 쓴다. 아티팩트는 외부 이미지를 차단하므로
썸네일은 `data:` URI 로 파일 안에 심어야 하며, `i.ytimg.com` 에 나갈 수 없는 환경에서는 자동으로
러닝타임 타일로 대체된다.

### 옵션

```bash
node fetch.mjs --days 60      # 최근 60일치만 (기본 120일)
node fetch.mjs --limit 20     # 주제당 최대 20편 (기본 14편)
node build.mjs --out /경로/widget.html
```

주제와 검색어는 `config.json` 에서 고친다. 쿼리를 늘리면 할당량도 쿼리당 100유닛씩 늘어난다.

### 프록시 뒤에서 실행할 때

Node 의 내장 `fetch` 는 `HTTPS_PROXY` 를 자동으로 읽지 않는다. 프록시가 있는 환경이라면 이렇게 실행한다.

```bash
NODE_USE_ENV_PROXY=1 YOUTUBE_API_KEY=AIza... npm run refresh
```

## 파일

```
config.json     주제 · 검색어 · 필터 기준
fetch.mjs       YouTube Data API v3 → data.json
build.mjs       data.json + template.html → dist/widget.html
template.html   위젯 UI (디자인 · 상호작용)
```
